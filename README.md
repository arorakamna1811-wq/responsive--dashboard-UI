# Responsive Dashboard UI

This project is a modern and responsive dashboard interface built using HTML and CSS. It includes a sidebar navigation menu and a clean card-based layout.

## 🔥 Features

- Sidebar navigation menu
- Dashboard cards (users, sales, revenue)
- Clean and minimal UI
- Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📱 Responsive Design

The layout adjusts for mobile and tablet screens using CSS media queries.

## 🚀 How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
